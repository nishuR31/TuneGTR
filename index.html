Made for musicians

Accuracy without the noise.

The essentials are engineered into one focused tuner: responsive detection, clear feedback and flexible setup.

Real-time pitch detection

An optimized YIN-based detector estimates pitch from live audio, with stability filtering to make note readings more dependable.

Alternative tunings

Switch between tuning presets and tailor your target notes instead of being locked into standard E–A–D–G–B–E.

Capo-aware targets

Capo support transposes target frequencies so the tuner can follow your setup, not force you to do the math.

Responsive waveform

A live SVG waveform responds to audio amplitude, giving you a visual indication of the incoming signal.

Adaptive interface

A clean layout adapts across portrait and landscape orientations, including larger phone and tablet screens.

Open-source code

Inspect the implementation, report issues and contribute improvements in the public GitHub repository.

Under the hood

From string vibration to a clear note.

TuneGTR turns microphone input into a pitch estimate and compares it against the selected string's target frequency.

01

Capture audio

The app requests microphone permission and reads the guitar signal from the device microphone while tuning is active.

02

Estimate fundamental pitch

The YIN pitch-detection algorithm analyzes the signal to estimate its fundamental frequency. Stability filtering helps reduce jumpy readings.

03

Compare against your target

The detected frequency is evaluated against the selected note, tuning preset and capo setting to determine pitch deviation.

04

Adjust and lock in

The interface indicates whether the string is flat or sharp and when it is close enough to the target to be in tune.

Privacy & security

Your audio should stay yours.

Permissions are explicit, and the project is open for inspection. Here is what the app's documented design means in practice.

Local audio processing

The app's permission description states that audio is processed locally and never recorded or uploaded. Tuning requires microphone access; deny it if you do not want to provide audio input.

Permission transparency

Android microphone access is requested for pitch detection. Review app permissions in Android settings and revoke microphone access whenever you choose.

Reviewable implementation

The source code is public on GitHub. Developers can inspect pitch detection, app permissions, dependencies and changes rather than relying only on marketing claims.

Builds and updates

Download from the linked project release and check the repository for source changes and release notes. Only install APKs from sources you trust.
